# Arcane asset pipeline

Trace the exact job/source/artifact/material/target mapping through generation, review, conversion, staging and receipts. Confirm the failing representation before editing; a preview and engine import make different claims.

For quality changes use reference-led silhouettes, believable branching/rock structure, attached foliage, production UV/PBR and target-appropriate topology/collision/LODs. Inspect actual multi-angle outputs; do not improve only the wording of the generation prompt. Do not insert Toolbox models without user request.

Retain original work during file reads, atomic publication and final commits. Preserve exact attribution after a lost ACK; never create a replacement job automatically. A known fully journaled failure differs from unknown ownership or publication.

Verify units, axes, pivots, normals, transparency and material channels across conversion. Keep unsupported formats explicit. A plugin placement is not Asset Manager upload or native visual acceptance. Follow current permission boundaries for any live engine work.
