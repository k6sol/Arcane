# Arcane knowledge

Start from docs/vault/Home.md and the active goal, not the entire vault. Current source/runtime evidence overrides stale notes. Put reusable project knowledge in shared notes and keep device-private receipts, credentials and raw private conversations outside Git.

For each milestone record changed behavior, exact revision, verification scope, unresolved issue and next action. Update a goal's acceptance items with evidence; check the full goal off only when all pass. Reopen it when a regression contradicts acceptance. Use the templates for meaningful decisions, bugs and sessions rather than logging every command.

Keep executable product skills in skills/arcane and developer skills in .agents/skills. Preserve their references, license and actual experimental/approval status. Validate meaningful skill behavior; do not imply that adding instructions trains a model.

Sync an explicit committed revision with scripts/sync-obsidian-vault.py. Check before apply. Merge local Obsidian edits back into shared source after review; never overwrite conflicts or publish personal notes automatically. Keep Current State and Next Session short enough to be useful on resume.
