## Required ease of use

- [ ] Drag chats into folders with a clear drag preview, valid drop target and visible result.
- [ ] Support keyboard-accessible Move to folder and usable touch alternatives.
- [ ] Make folder creation, rename and deletion reachable; deleting a folder must not silently delete its chats.
- [ ] Preserve active conversation, unsent text, history, provider/model/effort and authentication during organization.
- [ ] Handle empty folders, unfiled chats, cancel/Escape, scrolling and concurrent moves without losing a chat.
- [ ] Give selected Blender/Studio navigation a clear purpose and a reachable return to chat.
- [ ] Keep preview, settings and side panels from trapping or obscuring chat/composer controls.
- [ ] Show real actionable failure details and truthful incomplete task states.
- [ ] Match the supplied pages at relevant desktop widths and verify focus, contrast, reduced motion and narrow layouts.

The running desktop is a separate installed revision; compare it with source and the reference before attributing a visual difference to a newly published change. See [[Operations/Requirements Ledger]], [[Delivery/G02 Reliable Chat]] and [[Delivery/G10 Customer Release]].
