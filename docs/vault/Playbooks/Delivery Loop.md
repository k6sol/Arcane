# Delivery loop

1. Read [[Operations/Current State]] and choose the highest-impact unblocked item in [[Delivery/Goal Board]].
2. Define observable acceptance and the failing or missing behavior. Keep the full goal scope intact.
3. Read the relevant developer skill and current source. Assign separate paths if parallel contributors are already authorized.
4. Implement a reviewable improvement; preserve other work and original evidence.
5. Verify the actual changed behavior. Run relevant checks, expanding only for a new failure or unresolved concern.
6. Publish a concise SSH-signed change under the authorized repository workflow; inspect the resulting checks.
7. Add evidence to the goal and session note. Check completed acceptance items; mark the whole goal done only when all are proven.
8. Update [[Operations/Next Session]] with the next exact action.

When blocked, record the external dependency and progress independent work. Do not replace the full objective with a smaller success definition.
