# Release verification

Bind all evidence to an exact source revision. Inspect relevant job conclusions and their actual scope, not just a green overview. Retain attributable package metadata and verify installed identity separately.

Exercise startup, first setup, reopening, drafts, model selection, chat, preview return, cancellation and update/restart. Trace an asset through its approved export/import path; distinguish fixtures from actual native engine output. Use a clean customer environment where authorized.

A failed observation does not mean a running job ended: poll its exact handle. Never restart because a polling window expired. Do not operate Studio or the user's current app outside the active authorization. Record missing acceptance explicitly in [[Operations/Evidence Ledger]].
