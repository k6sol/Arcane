# Normal task handoff

Status: connected source implementation and regressions prepared; exact hosted acceptance pending.
Related goals: [[Delivery/G02 Reliable Chat]], [[Delivery/G04 Task Lifetimes]].

## Customer outcome

A genuinely completed task fences new admissions and joins its accepted work without cancelling it. The completed plan, evidence and model stay available for later human review. A later Send waits for the exact handoff, closes the original client through its owned close, then uses the existing fresh account/thread/model/process/credential checks. Local model choice during a pending normal join does not cancel accepted assets.

## Connected ownership

The session retains original managed request, acknowledgement and terminal references under the genuine continuation. Its scoped normal join does not interrupt the transport, clear unrelated reads or revoke manual preferences. The asset registry first fences new admissions while preserving acquired actors' existing scope checks. It joins actual lease finish and pending tails before retiring the original generation. Unknown work stays retained; normal joining alone never proves physical transport closure.

The coordinator starts normal retirement only from actual original events and quiescent plan/work evidence. Explicit Stop escalates the same original lifecycle and retains the first failure, including falsy thrown values. A real close Promise is cached before reentrant hooks. Only the expected original planned normal close or explicit original Stop suppresses the generic unexpected-retirement path; failed close still fails and cannot establish transport closure.

Later plan acceptance is a read of actual WorkStore evidence, independent of volatile resource retirement. A saved completed task may focus its genuine still-connected original client for reads under exact account/connection identity; the old continuation and asset credential remain fenced. A new Send rotates before effects. Scenario success, task acceptance, model approval, Keep consent and Studio import remain separate facts.
