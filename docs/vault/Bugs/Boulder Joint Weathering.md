# Boulder joint weathering

The retained seed31 boulder hero view showed dark connected polygon outlines dominating the surface. Exact source comparison attributes that earlier Linux render to the same current rock algorithms; its original job is not relabelled as a later revision. The broad cellular joint mask fed albedo, height and roughness together, giving the smooth mass an outlined paving-like appearance.

The candidate interrupts only boulder joints with a smooth gate from the already computed world-space medium field. It adds no random draws, geometry, new texture layer or global contrast multiplier.
