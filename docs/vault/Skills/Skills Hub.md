# Skills hub

## Two libraries

- [[Skills/Development Skills]] — skills for the developers building and maintaining Arcane.
- [[Skills/Skill Catalog]] — Arcane's existing game/asset production skill pack, projected with its references and registry.

Read only the relevant skill and its needed references. A skill helps choose a workflow; it does not expand permissions or prove the resulting feature works. Product skill approval/runtime integration remain governed by the actual registry. External locally installed skills are not silently copied into this public repository.
