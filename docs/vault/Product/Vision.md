# Product vision

Arcane is a premium chat-first Roblox development platform. The intended experience connects conversation, original asset creation, interactive review, scene integration, testing and repair in one durable project workflow.

Quality means a user can repeatedly inspect, change, test and restore a project without losing manual work. Models must survive export/import with correct geometry, materials and transforms. Completion requires observable results and honest unresolved limits.

The initial focus is dependable Windows local development using supported provider connections and the Arcane plugin. Optional hosted accounts and commerce remain part of production scope. Read the versioned `docs/PRODUCT_PLAN.md` for full requirements; this note is a navigation aid.
