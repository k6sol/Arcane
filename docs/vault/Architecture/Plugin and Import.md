# Plugin and import

The modular Arcane plugin handles supported pairing, project identity, scene operations and receipts. The daemon stages exact approved payloads and checks the intended target.

Trace source artifact → conversion manifest → staged payload → actual plugin receipt. Verify units, axes, pivots, hierarchy, textures, collision and source mapping at those boundaries. Placed geometry is not automatically an uploaded asset or an Asset Manager entry. A later update should target the original mapping and preserve unrelated manual edits.

Keep unsupported formats and engine claims explicit. Deletion uses the current authorized scene scope and observable outcomes; stale build receipts alone do not establish that all scene deletion is unavailable.
