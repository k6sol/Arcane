# Asset pipeline

Intended path: brief/reference → Blender geometry → UV/PBR → actual renders → review → validation → export → conversion → approved import.

Keep original source, generated artifacts, job identity, material mappings and evidence associated. A template or source implementation is not proof of visual quality. A GLB preview is not proof of safe native import or Asset Manager registration.

Production checks include connected foliage, credible branching/rock structure, topology, UV coverage, texture interpretation, scale, pivots, transforms, collision and target budgets. Preserve the user's requested aesthetic; Toolbox models require explicit request.
