# Collection / simulator

## Player decision
Select an activity, equipment or area with a meaningful efficiency/risk trade-off.

## Craft priorities
Satisfying repeat action and useful variation instead of an empty exponential number treadmill.

## Representative vertical slice
One collection action, two approaches and a visible upgrade that changes play.

## Player and technical checks
Observe action satisfaction and informed upgrades; check extreme economy growth and rewarded replay.

Preserve the user's actual brief and audience. A hybrid uses only the parts that serve its primary loop. Keep monetization optional and separate. Block out and test this slice before scaling content; neither technical correctness nor this profile proves that the game will be popular.
