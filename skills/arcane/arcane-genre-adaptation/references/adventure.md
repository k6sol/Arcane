# Adventure / exploration

The player chooses a destination or tool approach, discovers useful information and acts on it. Give exploration purpose through landmarks, routes, mysteries and consequences; an enormous terrain with scattered pickups is not automatically an adventure.

## An authored route through discovery

Prove one explorable area, a useful tool/discovery, alternate approaches and return/recovery. For a full request, connect the promised regions, revelations and challenges into a journey with a meaningful ending or continuing goal. Later areas should change the player's understanding or capability rather than only gate a recolored zone. Optional routes need useful identity/rewards without becoming mandatory chores.

Build a dependency graph for tools, passages, information and objectives so no required item is stranded behind its own lock. Define shared-world pickups, checkpoint/death recovery, world changes and requested save/rejoin. Streaming cannot silently delete required context or leave a player in invalid saved coordinates. The server validates progression and rewards; client discovery presentation alone does not grant authority.

## Environment, character and interface

Use readable distant landmarks, framed local affordances, grounded traversal and original themed props. Environmental storytelling should point toward playable investigation, not only decorate walls. Characters/dialogue, actual tool animations, positional ambience and restrained discovery effects support the chosen mood. The objective/journal/map, if appropriate, helps orientation without spoiling every surprise. Support non-audio/color clues and target-device input. Real custom authoring needs actual capabilities/grants and supported export limits; no invented media IDs or Toolbox replacement unless requested.

Observe players navigating without narration, finding a discovery and using it to make another decision. Test required paths, alternative approaches, dead ends, lost items, death/retry, streamed transitions and requested rejoin. Visit later delivered regions instead of testing only spawn. Distinguish source/fixture checks, known-route automation and genuine exploration/visual review. `arcane-rpg-kit`, level/world-building, onboarding and input-camera skills provide relevant pieces; a large map and a quest tracker do not establish a finished adventure.
