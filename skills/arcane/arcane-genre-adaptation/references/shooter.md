# Shooter / tactical combat

## Player decision
Choose position, timing, weapon use and team contribution.

## Craft priorities
Readable cover, responsive feedback, bounded latency handling and distinct range roles.

## Representative vertical slice
One arena, a small weapon set and a complete spawn/fight/result/retry flow.

## Player and technical checks
Check spawn traps, hit-validation edges, device input and counterplay under latency.

Preserve the user's actual brief and audience. A hybrid uses only the parts that serve its primary loop. Keep monetization optional and separate. Block out and test this slice before scaling content; neither technical correctness nor this profile proves that the game will be popular.
