# Tycoon / builder

## Player decision
Spend limited resources on capacity, efficiency or a different production path.

## Craft priorities
Visible production cause/effect, readable build choices and recoverable placement.

## Representative vertical slice
One small production chain with two non-equivalent upgrades and a save/rejoin case.

## Player and technical checks
Check that both upgrades have situational value; test ownership and purchase replay.

Preserve the user's actual brief and audience. A hybrid uses only the parts that serve its primary loop. Keep monetization optional and separate. Block out and test this slice before scaling content; neither technical correctness nor this profile proves that the game will be popular.
