# Select a genre profile, then deliver its actual scope

Read only the primary profile relevant to the brief. For a hybrid, name what each secondary loop contributes; do not load every profile or paste all mechanics into one game. A slice proves the risky interaction first. It does not complete a request for a whole game, and a small repair does not require a new campaign, economy or content roster.

Profiles are original design guidance, not popularity guarantees, asset licenses or executable capabilities. Honor the user's actual audience, art references and existing game. Progression, monetization, combat and narrative are conditional. Scale content to the request with meaningful differences rather than universal map counts; preserve real tool grants, supported inputs and human playtest review. A profile, source pass or screenshot cannot establish fun, retention, complete content, multiplayer fairness or native engine acceptance.
