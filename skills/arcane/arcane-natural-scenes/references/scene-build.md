# scene_build and terrain_generate field guide

The tool schemas carry types and limits; this is what each field means.

## scene_build
- `name` names the container: Model (default) or Folder. ScreenGui: `parent` is the StarterGui root ref, GUI items only, `screen` = its props.
- `defaults`: part props applied before each part's own. Part props: Size/Position/Orientation [x,y,z], Color [r,g,b] 0..1 or "#rrggbb", Material, Shape, Anchored (default true), CanCollide, CastShadow, Transparency, Reflectance.
- `prototypes` {Name: {parts, weld, ui}}: part Position/Orientation are local to a ground-level origin; Size scales with the placement. Part `tint: false` keeps its colour under a placement tint. `weld` welds parts to the first (if unanchored). `ui` is a GUI element tree instead (first = root; `in` = an earlier element, default root), stamped N times by items `use`; the item's `ui` overrides the root.
- `templates` {name: ref}: original Model/BasePart refs from assets_place_studio_import (other refs need the Settings opt-in). Each use is a full copy scaled/yawed about its bottom pivot; no tint.
- `items`: `key` is a local id (its ref is returned; later items name it in `in`). `in` is the key of an earlier group, or for effects/GUI also a part, Attachment or GUI host; default the root. `className`: Model/Folder group, part (default Part), an effect class with `fx` (refs = earlier item keys) or a GUI class with `ui`, as on scene_create. Placement: `use` (prototype or template), `at`, `yaw`, `scale`, `tint` (per-channel multiplier 0..2); `ground: true` drops it onto the surface.
- `scatter` (16 layers max): `use` is one name or a list, one per point (repeat a name to weight it). `center` [x,y,z], y = ground height. Area: `radius`/`innerRadius`, or a rectangle `size` [w,d]. `minSpacing`: Poisson-disk spacing at scale 1; it also clears earlier scatter points. `clusters`: natural clump count (`clusterSpread`). `clearing` {center [x,z], inner, outer}: none within inner, full density from outer. `avoid`: keep-out circles [{at [x,z], radius}]. `avoidPaths`: full-width [x,z] corridors, endpoints included. `footprintRadius`: scale-1 canopy radius that pads clearing, avoid and paths. `yaw` and `scale` ranges (scale default [0.75,1.25]), `tint` {min,max}, `seed`, `ground`. `edge`: rim fade studs. `tilt`: max lean degrees. `hug` 0..1: share placed by earlier trunks (undergrowth).

## scene_build kits
- `plinth`: round stepped stone at `at` (ground centre): `radius` (default 10), `tiers` (default 3), `style` smooth (default), fluted (only if classical) or platform; column `height` (default 18) or `column` = a template/prototype shaft; `material` (Limestone default, Marble trim), `color`, `weathering` (default 0.5); `spawn` (default true) puts a SpawnLocation on top: verify result kits spawn.top. `life` day: motes + rune light; dusk: fireflies; both add ambience sounds. `safeZone` {radius >= plinth radius + 2.5, style glow|stone}: a ground ring plus a no-damage Script in the report.
- `forest`: `at` ground centre, `radius` 16..2048. `trees` (default 80) pine/oak/birch groves; `undergrowth` (default 2x trees) bush/fern/rock/log cover at trunks. `species`/`cover` layers {use, share, spacing, tris} replace the defaults. Per-layer spacing, clearing (default: around the first plinth) and rim falloff, lean and ground drop. `paths`: avoidPaths for every layer.
- An undeclared `use` takes templates `<use>-1..n`, else a blockout (reported).

## Variation (no identical copies)
- Generate: one assets_procedural call per member with the same seed and params plus `variant` [i, n] (n 2..16, not column). The family is low-discrepancy (scrambled Halton, one stratum per member), correlated (older = taller, wider crown, thicker trunk, mossier and darker bark, more canopy damage) and never near-duplicate. i = 1 is the youngest/smallest. Trees lean towards local +X so placement yaw sets the direction; natural finish varies texture tone (flat keeps colour).
- Place: forest kits read world-space maps: warped Voronoi groves per species with soft transitions, an age map (old interior, saplings at clearing and rim edges) that picks the member and scale, a moisture/relief map for species and cover preference, and a lean heading towards the clearing light. Nearby copies of one member never share a similar yaw. Clones vary by member, uniform scale and yaw only (no tint or tilt); blockouts also get map tint and tilt.
- Budget: 240 trees at 16k triangles exceed the 3M kit cap; use triangleBudget 8000 and layer `tris`.

## terrain_generate
- `center` [x,z] and `size` [width,depth] studs. `floor`: world Y of the region bottom; `height`: region cap above floor; `baseHeight`: ground level above floor. Every height is studs above floor.
- `noise` {type fbm|ridged, octaves, frequency (cycles per 1000 studs), amplitude, persistence}. `edge`: fade noise to baseHeight near the border. `snowLine`: default rules put Snow above it.
- `features`, applied in order. hill/mountain/valley/crater {center, radius, height = rise (depth for valley/crater), roughness = mountain ridge detail}. plateau/flatten {level = flat surface (flatten defaults to the ground at center), blend = soft edge studs, material, base = landmark radius: adds Ground, Mud, Rock rings in to it (pad default LeafyGrass)}. lake {level = water surface, depth, material = bed (default Mud)}. river/path {points, width, depth = carve below centreline ground (river 8, path 0.5), bank = side slope studs (default width), material (river Pebble, path Ground)}.
- `materials`: `rules` (first match wins; they replace the defaults) {material, min/maxHeight, min/maxSlope, min/maxNoise -1..1, nearWater studs}; `fallback` (default Grass); `deep` (below 12 studs and cliffs, default Rock). Defaults: Sand at shores, Mud near water, Rock/Slate on steep slopes, Ground on mid slopes, Grass/LeafyGrass elsewhere.
- `caves` {at = rock outcrop centre (mouths open on its flanks), radius, rise = outcrop height (0: use existing hills), entrances, chambers, tunnel = tunnel radius, floor (default Slate), avoid = [x,z,r] keep-outs (pads are always kept out)}. result.caves lists mouths, chambers and scene_build fixtures.
