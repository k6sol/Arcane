# Efficient evidence and context budgets

## Retrieve what changes a decision
Start with skill metadata and task scope. Load relevant entrypoints, then exact source spans and conditional references. Avoid entire game dumps, repeated manuals, binary/base64 media and loading every domain skill for a small edit.

Cache facts with provenance and revision; never use a stale summary as the base for a patch. A compact handoff preserves objective, constraints, current target, changed artifacts, unresolved facts and next acceptance check. Large images/logs remain artifact references with selected evidence.

Use deterministic tools for repeated transformations where they are actually verified. Batch independent bounded reads when it helps, but do not batch mutations whose order or outcomes depend on each other. Keep model choice/effort under the user's control.

## Verification
Measure context bytes and provider-reported tokens when available; do not convert bytes to exact tokens or estimate hidden subscription quota as zero. Compare acceptance results, corrections and elapsed work as well as context size. Never omit a conflict, failed test or rights requirement solely to save context.
