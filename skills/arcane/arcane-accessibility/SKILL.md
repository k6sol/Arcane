# Accessibility and inclusive controls

## Preserve challenge, remove needless barriers
Identify which information and actions players need to succeed. Separate intentional difficulty from unreadable text, colour-only warnings, inaccessible controls and uncontrolled motion. Respect the user's audience and existing preferences.

Provide redundant cues for essential events, readable text and clear interaction focus. Where motion sensitivity matters, expose meaningful shake/flash/camera options without hiding gameplay-critical feedback. Audio alternatives should communicate purpose, not caption every irrelevant sound.

Inspect touch target spacing, controller navigation, text entry and screen safe areas. Consider timed actions and remapping where appropriate. Do not claim accessibility compliance from one automated contrast result or add accessibility settings that do not actually affect play.

## Verification
Run the critical path with advertised device inputs and selected accessibility options. Check failure/success states and menus as well as ideal gameplay. Use captures and action traces, then representative player feedback. State untested accommodations and avoid making the entire game trivially easy as a substitute for accessible presentation.
