# Avatars and wearable integration

## Determine the product type
Identify whether this is an in-experience cosmetic, classic/layered clothing, accessory or marketplace publication. Verify current format, rig/cage/attachment and account/publication requirements for that type rather than treating all meshes as interchangeable.

Match the intended bodies and animation ranges. Test fit, clipping, scaling, layering and attachment behavior with representative avatars. Preserve base rig and gameplay state when changing cosmetics. Do not presume arbitrary reference art provides rights to distribute a recognizable design.

Keep source and export validation, creator ownership and publication state separate. An item that works in a private place is not automatically compliant or eligible for public sale.

## Verification
Inspect supported body/pose combinations, equip/unequip, respawn and observer view. Validate the actual target pipeline and document unsupported combinations. Publishing needs explicit scope and any required certification; a render or successful local import is not the final wearable gate.
