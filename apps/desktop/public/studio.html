        Guide
        Describe what you want in plain words. Arcane plans it, builds it in Roblox Studio and shows you every change.
        Getting started
        1. Sign in: choose ChatGPT or Claude under General › Provider.
        2. Install the plugin: General › Studio plugin › Install plugin, then restart Roblox Studio.
        3. Pair Studio: click Connect Studio (setup checklist or General › Studio plugin), type the 6-digit code it shows into the Arcane plugin in Studio and click Connect. Then click Approve here when Arcane shows your place. An API key from General still works as a fallback.
        4. Open your place in Studio, then send your first message here.
        What you can ask for

        “Generate a carved wooden throne when nothing fits”
        Tips for great results
        • Be specific: say what, where and how many.
        • Name the style, scale and mood: “low-poly”, “human-sized”, “eerie at night”.
        • Select something in Studio and write @selection to work on exactly that.
        • Turn on Playtest in the message box to let Arcane check gameplay with a short playtest.
        • Check the viewport after a build, then ask for fixes in your own words.
        Permissions & safety
        • Auto-approve (General › Permissions) accepts edits and tool use inside this project.
        • Arcane still asks first before deleting files, using the network, installing, publishing or touching secrets.
        • Assets are never bought or published for you.
        • Every Studio change gets a receipt. The card after each reply has Restore, which drafts an undo request you review before sending.
        • Stop is always available, mid-reply.
        Costs & plans
        • Each reply shows its tokens and a ~cost estimate at API prices. It is not a charge; subscriptions are not billed per token.
        • Hide estimates or change the currency under General › Display.
        • One Arcane action is one finished build turn or one applied Studio change. Track them in Plans & credits.
