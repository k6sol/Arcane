Get started

Already signed in? Refresh native status below.

  1. Install a provider CLI

    A CLI is the provider's terminal app. Install Codex or Claude Code on the same computer and user account as Arcane.

    Install with npm

    With Node.js 24 or later and npm installed, open a terminal (PowerShell on Windows). Run the command for your chosen provider. Installation needs internet access.

    Codexnpm install -g @openai/codex@latest
    Claude Codenpm install -g @anthropic-ai/claude-code

    Open a new terminal and check codex --version or claude --version. If Arcane still cannot find it, restart Arcane to pick up the new installation.

  2. Sign in from your terminal

    Run the command for your provider and finish its browser sign-in. Use your subscription account to save a preference in this lab.

    Codexcodex login
    Claude Codeclaude auth login

  3. Check and choose

    Return here and select Refresh native status. Choose a provider, a reported model and reasoning effort, then select Save preference.

    Saving records your request. It does not start a task or apply the choice to a running conversation.

A preference is a request

This lab reads metadata and saves your choice. It does not launch coding, image generation, browser tools or publishing. Usage, remaining allowance and billing are not checked here.

Connection warnings & limitations

    Missing CLI: check its version in a new terminal, then restart Arcane if needed. Signed out: finish the native login and refresh. No models: review any provider warnings and refresh again.

    The lab does not validate model access by running a task. Requested settings need confirmation from the runtime that will actually use them.
